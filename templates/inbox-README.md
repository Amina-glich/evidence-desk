# Inbox: add your papers here

Put the PDF papers you want to compare in this folder.

To upload: keep this `inbox/` folder open in the project's file list, choose
**Upload** in the file list toolbar and pick your PDF files. Upload adds files
to the folder that is open, so a PDF uploaded while another folder is open
ends up there instead.

Then ask the agent in the project chat to register them. Evidence Desk and
the agent read files here but never change or delete them.
